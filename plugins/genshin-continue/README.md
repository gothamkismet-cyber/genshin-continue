# genshin-continue 「继续」下载原神

一个 ZCode 插件：在对话里输入「**继续**」两个字，自动在后台下载**米哈游启动器**安装包——原神 PC 端当前的官方安装入口。下载完成后双击安装启动器，再在启动器里下载原神本体即可。

> 名字里的梗：别人聊天打「继续」，你的电脑已经开始下原神了。

## 功能

- 监听每次输入，**仅当去掉首尾空白后恰好是「继续」两个字**才触发；其他输入一律不干预，对话照常进行。
- 从米哈游官网配置的官方短链（`https://mhyurl.cn/Ztkut6sBd`）实时解析当前安装包地址并下载，米哈游更新版本后无需改插件。
- 安装包（约 200 MB）保存到「下载」文件夹；下载进行中再次触发会自动跳过，不会重复下载。
- 提供 `/genshin` 斜杠命令，可随时手动触发同样的下载。
- 全部进度与结果写入日志，方便排查。

## 安装

### 方式一：添加本仓库作为插件市场

在 ZCode 中打开 **插件市场 → 添加 → 添加插件市场**，粘贴本仓库地址（GitHub 链接或本仓库克隆到本地后的目录）。添加后在 **个人** 页找到「继续下载原神」，点击安装。

> 本仓库根目录带 `.claude-plugin/marketplace.json`，是标准的插件市场格式。若你的 ZCode 版本暂不支持 Git 源，请用方式二。

### 方式二：本地目录

```bash
git clone https://github.com/<你的用户名>/genshin-continue.git
```

在 **插件市场 → 添加 → 添加插件市场** 中粘贴克隆出的 `genshin-continue` 目录（含 `.claude-plugin` 的这一层），然后到 **个人** 页安装。

## 使用

| 输入 | 效果 |
| --- | --- |
| `继续` | 注入一条提示，后台开始下载安装包 |
| `继续。` / `继续啊` / `请继续` | 不触发（不是恰好两个字） |
| `/genshin` | 手动触发同一次下载 |

下载中再次触发会自动跳过；下载完成后米哈游启动器安装包出现在「下载」文件夹。

## 工作原理

```text
输入「继续」
   │  UserPromptSubmit 钩子（hooks/scripts/genshin-continue.ps1）
   ├─ 不是「继续」→ 静默退出，对话不受影响
   └─ 是「继续」→ 拉起独立后台进程（hooks/scripts/do-download.ps1）
                    ├─ 解析官方短链 → hyp-webstatic.mihoyo.com/.../miHoYoLauncher_x.exe
                    ├─ 探测总大小（Range 请求）→ 流式下载到「下载」文件夹
                    └─ 锁文件防重复（%TEMP%\genshin-continue.lock）
```

- 日志：`%TEMP%\genshin-continue.log`
- 锁文件：`%TEMP%\genshin-continue.lock`（进程退出自动释放，残留的死锁会在下次触发时自动清理）

## 常见问题

**怎么让它停下？**
设置 → 插件 → 关闭 genshin-continue；或直接卸载。注意「继续」是高频词，插件启用期间任何任务里单独输入「继续」都会触发下载。

**下载失败了？**
看 `%TEMP%\genshin-continue.log` 的最后几行。通常是短链解析或网络问题；脚本内置了硬编码回退地址（`hyp-webstatic.mihoyo.com/hyp-client/miHoYoLauncher_1.18.exe`），可能随后续版本过期，届时更新插件即可。

**为什么下的是启动器而不是游戏本体？**
原神 PC 端现已并入米哈游启动器（HoYoPlay）分发，官方不再提供独立游戏安装包；本插件下载的启动器就是官方认可的安装入口。
