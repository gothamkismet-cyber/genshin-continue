# genshin-continue 「继续」下载原神

一个 ZCode 插件：在对话里输入「**继续**」两个字，自动在后台完成下载米哈游启动器的全部准备——下载安装包（断点续传）→ 打开官方安装向导（点一次「安装」）→ 装完自动打开启动器 → 在启动器里点击原神的下载按钮即可，本体的 100GB+ 下载由官方启动器负责并原生支持断点续传。

> 名字里的梗：别人聊天打「继续」，你的电脑已经开始下原神了。

## 功能

- 监听每次输入，**仅当去掉首尾空白后恰好是「继续」两个字**才触发；其他输入一律不干预，对话照常进行。
- 从米哈游官网配置的官方短链（`https://mhyurl.cn/Ztkut6sBd`）实时解析当前安装包地址，米哈游更新版本后无需改插件。
- 安装包（约 200 MB）下载到「下载」文件夹，**HTTP Range 断点续传**：中断后再次触发从断点继续，官方换包则自动作废旧进度。
- 已装过启动器时再触发，直接拉起 HoYoPlay，不重复下载安装。
- 提供 `/genshin` 斜杠命令，可随时手动触发同样的流程。
- 全部进度与结果写入日志，方便排查。

## 安装

### 方式一：添加本仓库作为插件市场

在 ZCode 中打开 **插件市场 → 添加 → 添加插件市场**，粘贴本仓库地址（GitHub 链接或本仓库克隆到本地后的目录）。添加后在 **个人** 页找到「继续下载原神」，点击安装。

> 本仓库根目录带 `.claude-plugin/marketplace.json`，是标准的插件市场格式。若你的 ZCode 版本暂不支持 Git 源，请用方式二。

### 方式二：本地目录

```bash
git clone https://github.com/gothamkismet-cyber/genshin-continue.git
```

在 **插件市场 → 添加 → 添加插件市场** 中粘贴克隆出的 `genshin-continue` 目录（含 `.claude-plugin` 的这一层），然后到 **个人** 页安装。

## 使用

| 输入 | 效果 |
| --- | --- |
| `继续` | 后台下载安装包（续传）→ 弹出官方安装向导（点一次「安装」）→ 自动打开启动器 |
| `继续。` / `继续啊` / `请继续` | 不触发（不是恰好两个字） |
| `/genshin` | 手动触发同一次流程 |

## 工作原理

```text
输入「继续」
   │  UserPromptSubmit 钩子（hooks/scripts/genshin-continue.ps1）
   ├─ 不是「继续」→ 静默退出，对话不受影响
   └─ 是「继续」→ 拉起独立后台进程（hooks/scripts/do-download.ps1）
                    ├─ 已装 HoYoPlay？→ 直接拉起启动器
                    ├─ 未装 → 解析官方短链 → Range 断点续传下载安装包
                    │         （状态文件 %TEMP%\genshin-continue.state，官方换包自动作废旧进度）
                    ├─ 打开官方安装向导，等用户点「安装」→ 向导关闭后自动检测注册表
                    └─ 检测到安装完成 → 拉起 HoYoPlay
                         └─ 原神本体 100GB+ 在启动器内下载，官方原生断点续传
```

- 日志：`%TEMP%\genshin-continue.log`
- 锁文件：`%TEMP%\genshin-continue.lock`（任务进行中重复触发自动跳过）
- 后台进程独立于 ZCode 运行，**关闭 ZCode 不影响下载和安装**

## 常见问题

**为什么还要点一次「安装」？**
实测米哈游启动器安装器（NSIS 外壳 + 自定义向导）不响应任何静默安装开关，`/S` 会在解压中途退出，所以安装这一步必须人工点击。插件把下载、续传、打开向导、装后接管全部自动化了，人工只剩一次点击。

**原神本体为什么不在插件里直接下？**
原神 PC 端本体（100GB+）官方只通过启动器分发，公开 API 已拿不到当前版本的独立安装包直链；而 HoYoPlay 的下载本身支持断点续传（关机重开自动继续），比自建下载器更可靠。插件把启动器之路铺到"一键之遥"。

**怎么让它停下？**
设置 → 插件 → 关闭 genshin-continue；或直接卸载。注意「继续」是高频词，插件启用期间任何任务里单独输入「继续」都会触发流程。

**下载/安装失败了？**
看 `%TEMP%\genshin-continue.log` 的最后几行。安装包下载失败会在下次触发时自动续传；向导被关闭但未安装时，下次触发直接重开向导，不用重新下载。
